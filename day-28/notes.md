Exploring Solana explorer-
To check transaction details in Solana, Solana explorer or Solscan is used.

Solscan contains DeFi snd NFT related details as well which is one of the reasons for it being widely used . 

Solscan contains terms like-
1. Epoch
2. SOL Supply
3. Blocks
4. Transaction
5. TPS

Epoch: It is a fixed group of slots. On Solana mainnet, an epoch usually lasts around 2–3 days. Once the fixed number of slots gets crossed, certain network operations—such as validator rewards and stake activation/deactivation are processed. Solscan shows the number of slots ,time remaining and the epoch number. 

SOL Supply: This section in Solscan contains two subsections- Circulating SOL and Non-circulating SOL. The total percentage of both is 99.99%. This is due to rounding erros in decimal formatting.
   
Blocks: This section is like a table with columns- Block hash, Slot, Time , Leader, Transaction count, Reward. 
   
Transaction: This section is also in the form of table with columns- Signature, Block, Time, Instruction, Address (By), Fee

TPS: This section shows a graph of the number of transactions processed per second, gives an overview of the network's activity.
