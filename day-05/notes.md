Wallet Interfaces -
1. CLI wallet :
   It is a command-line based wallet integration through tools like -- Solana CLI
   using commands like 
    a. solana-keygen
    b. solana address 
    c. solana balance
    This wallet is used mainly by developers.

2. Browser extension wallet:
  These wallets can be accessed through browser extensions. Some commonly used browser extension wallets are  Phantom, Solflare and Backpack. 
  These wallets are used for-
   a. dapp connection.
   b. Signing transaction
   c. Interacting with Web3 applications

3. Mobile Wallet:
   Mobile wallets often support biometric authentication alongside a password.Mobile wallets follow similar seed phrase backup and recorvery mechaninsm as browser wallets. 

Wallet security models-

1. Hardware wallet:
   In this , the private key is stored in a physical device . The key is never shared even at the time of signing a transaction.
   It is a cold wallet.

2. Multisig wallet:
   Requires multiple people to approve a transaction before execution. 

Each wallet has its pros and cons , one needs to select a wallet based on the requirements and the level of security.
