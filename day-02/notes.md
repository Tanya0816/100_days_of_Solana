1. Persistent Wallet : 
   It is used to store private key and public key locally. This helps developers as they do not need to enter their keys repeatedly as they can use the same wallet identity .
   These keys can be exported and used for development purposes.  

2. Solana Wallet Integration :
   Solana applications use Solana Wallet Adapter and Mobile Wallet Adapter. 
   These adapters enable dApps to connect to wallets for authentication and transaction signing.
