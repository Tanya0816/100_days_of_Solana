Today I explored accounts in details -

In web2 , to access or check the stored data, database is used .

The same way , in Web3 , accounts are used to access or check the data stored onchain.

In Solana, accounts have 5 fields:
1. lamports
2. data
3. owner
4. executable
5. rent_epoch.

Each account has a unique 32-byte address which helps in identifying the account. 

The address is of two types -
1. A public key
2. Program Derived Address
   
Public key- It is always generated in pair with a private key . The public key can be viewed by the public but the private key needs to be kept safe and hidden. 

Program Derived Address-The address is deterministically generated by a program using program ID and a set of seeds. These addresses are owned  entirely by a program (smart contract). PDAs act as decentralized lockers. Only the program whose ID was used in the derivation can sign for a PDA. The PDA act as a specialized smart locker while the user's public key act as the account owner.

Note : The same bump seeds and program ID always produce the same address.  PDA cannot function without a user's wallet to initiate and pay for transactions.
