Token Pragrams in solana

Token programs are the smart contracts that creates and manages assets(tokens) and performs actions. 

A token's properties can be defined by using 'Mint accounts' whereas in token program, SPL Token Program and Token-2022 are used.

In solana, to create or transfer tokens , no new contract is created but these programs are used which instruct the blockchain .
 Blockchain creates a  new 'Mint Account' to define the token and create a Token Account to hold the token balance for specific user.

SPL - It stands for Solana Program Library. SPL tokens are different from SOL (native token of Solana). SPL token can be created by anyone but SOL can only be created according by the Solana network protocol . SPL tokens can be used to create new applications whole SOL is used to power the Solana network.
