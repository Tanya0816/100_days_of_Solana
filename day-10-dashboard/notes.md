This is day 10 of learning and building in Solana 

I build-

A web dashboard to fetch and display recent transaction details instead of fetching the details in terminal .

This page can be used to fetch details of last 5 transaction done by any given address.

I used Vite which is a lightweight dev server to build the web page . 

The script I used for building web page is almost similar to what I used for fetching details in terminal.

The difference I see in fetching details in terminal Vs in Web  page is the error handling.
  In terminal, it is not much necessary to show every detail and reason for error.
  But in web page, it is important to display proper message to show user the reason behind the error. 

Proper error handling and user feedback are important aspects of building user-friendly web applications.
