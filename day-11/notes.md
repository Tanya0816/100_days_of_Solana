Things I learned -

Like in traditional database where every user's record is stored, in Solana , account acts like database and stores all the details of the user.

In traditional database, tables are used to store information systematically, In Solana, the user's information lives in a global ledger which is maintained by all the validators. Hence there is no use of tables in Solana  for storing information.

Like in database, based on the database used, the developer is asked to pay fees for the database.
This fees is same for all the developers using that platform. Ths same way  in Solana, the rent on the basis of need of data storage  is asked to be payed . The value of rent in Solana increases with the increase in the need of data storage space.

Traditional databases are private by default until a developer chose to show it to everyone else. In solana, the account is public by default and everyone can read the account details.
