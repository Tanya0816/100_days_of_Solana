Why do we need tokens -
In web3, tokens can be used for multiple reasons. Tokens function as programmable digital assets used to incentivize networks, represent physical or virtual ownership and enable decentralized governance. 

Token creation - 
On EVM-compatible networks tokens are created by writing and deploying a smart contract using a standardized template, such as the ERC-20 Token Standard.

In Solana, the token creation is different from EVM due to architecture. The tokens are not created by deploying new smart contract , instead Solana's native Token Program is used . 

Metaplex token standard -
In Solana,  the foundational framework used to attach metadata, rules and custom functionality including NFT.
It utilizes a separate Metadata Account.
