# Day 1 — Keypairs and Wallets

## What I Learned

### 1. Solana uses cryptographic keypairs
- Private key signs transactions
- Public key acts as account address

### 2. Solana is not EVM-compatible
It cannot be added to MetaMask using RPC URL + Chain ID.

### 3. Solana uses its own wallet ecosystem
Examples:
- Phantom
- Solflare

### 4. Smart contracts are called Programs
